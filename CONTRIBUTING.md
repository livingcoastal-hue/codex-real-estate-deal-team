# Contributing

Keep this skill practical and decision-oriented.

## Guidelines

- Keep `SKILL.md` concise.
- Put detailed procedures in `references/`.
- Put reusable output formats in `assets/templates/`.
- Separate facts, assumptions, estimates, risks, and next actions.
- Do not add legal, tax, securities, or investment advice.

## Validation

Before publishing changes, check that:

- `SKILL.md` has YAML frontmatter with only `name` and `description`.
- The skill name is lowercase hyphen-case.
- The description explains both what the skill does and when to use it.
- Templates are plain Markdown and easy to copy into a live deal workflow.
